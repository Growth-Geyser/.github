# Contributing

1. Branch from the default branch: `feat/<short-name>`, `fix/<short-name>`, `chore/<short-name>` or `docs/<short-name>`.
2. Small commits with clear messages (`fix(baa): …`, `feat: …`).
3. Open a pull request using the template; a maintainer approves the merge.
4. Delete the branch after merging.
5. Never commit secrets, `.env` files, keys, client data or generated output. Secrets live in a secrets manager.
